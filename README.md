# Semi-Arcade Mini Golf Game – University Project

This is a semi-arcade mini-golf game with physics-based behavior, developed as a university group project using the Godot Engine.  
The project focuses on implementing core game mechanics, physics interactions, and a modular structure for level design and expansion.

---

## Installation
1. Clone this repository  
2. Open with Godot 4.x  
3. Run main scene: main.tscn  

---

## Project Goals
- Implement realistic physics gameplay using Godot Engine  
- Develop intuitive controls and user interface  
- Create modular and visually consistent level elements  
- Design reusable mechanics and components  
- Learn and apply team collaboration in game development  

---

## Key Features
- Dynamic strike force control (hold, cancel, reset)  
- Interactive objects: stars, jump pad, power-ups, etc.  
- Level checkpoint system  
- Collision system with custom friction and bouncing behavior  
- Wind effect influencing the ball and other physical objects  
- Basic animation and object feedback
